# 组件总览

Framebase 按使用场景将组件分为四类。下表列出全部组件及其用途,点击链接查看详细文档与示例。

## 数据展示

| 组件                                            | 说明                                  |
| ----------------------------------------------- | ------------------------------------- |
| [ProCard](/components/pro-card)                 | 内容卡片,统一标题、操作区与边距规范。 |
| ProStatisticCard                                | 统计卡片,内置数值与趋势展示。         |
| [ProDescriptions](/components/pro-descriptions) | 描述列表,Schema 化的详情展示。        |
| [ProList](/components/pro-list)                 | 列表,支持选择、分页与自定义渲染。     |
| [ProEmpty](/components/pro-empty)               | 空状态占位。                          |
| [ProResult](/components/pro-result)             | 结果页,统一成功/失败/警告反馈。       |
| [ProStatus](/components/pro-status)             | 状态点、状态标签与自定义语义颜色。    |
| [ProBadge](/components/pro-badge)               | 通知红点、数量徽标与自定义颜色。      |

## 操作反馈

| 组件                                               | 说明                                   |
| -------------------------------------------------- | -------------------------------------- |
| [ProAsyncButton](/components/pro-async-button)     | 自动加载、防重复执行与异步结果反馈。   |
| [ProConfirmButton](/components/pro-confirm-button) | 危险操作确认、异步执行与显式权限控制。 |

## 数据录入

| 组件                                               | 说明                                               |
| -------------------------------------------------- | -------------------------------------------------- |
| [ProField](/components/pro-field)                  | 统一字段,覆盖文本/数字/日期/枚举/状态/金额等类型。 |
| [ProForm](/components/pro-form)                    | Schema 驱动表单,内置联动与校验。                   |
| [ProModalForm](/components/pro-modal-form)         | 弹窗表单,弹窗与表单一体化。                        |
| [ProDrawerForm](/components/pro-drawer-form)       | 抽屉表单。                                         |
| [ProStepsForm](/components/pro-steps-form)         | 分步表单。                                         |
| [ProSelect](/components/pro-select)                | 选择器,支持远程搜索与缓存。                        |
| [ProRadioGroup](/components/pro-radio-group)       | 单选组。                                           |
| [ProCheckboxGroup](/components/pro-checkbox-group) | 复选组。                                           |
| [ProCheckCard](/components/pro-check-card)         | 选择卡片。                                         |
| ProCheckCardGroup                                  | 选择卡片组。                                       |
| [ProTree](/components/pro-tree)                    | 树。                                               |
| ProTreeSelect                                      | 树选择器。                                         |

## 复杂数据

| 组件                                                | 说明                                    |
| --------------------------------------------------- | --------------------------------------- |
| [ProTable](/components/pro-table)                   | 请求驱动表格,分页/选择/列设置开箱即用。 |
| [ProEditableTable](/components/pro-editable-table)  | 可编辑表格,行编辑/新增/校验/保存/删除。 |
| [ProDragSortTable](/components/pro-drag-sort-table) | 拖拽排序表格。                          |

## 文件与配置

| 组件                                                 | 说明                 |
| ---------------------------------------------------- | -------------------- |

| [ProUploadList](/components/pro-upload-list)         | 批量上传与列表管理。 |
